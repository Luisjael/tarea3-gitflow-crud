# Proyecto CRUD - Tarea 3 (Git y Git Flow)

API de gestión de tareas (Task Manager) con Node.js y Express, usada como
base para implementar la metodología Git Flow: ramas feature/hotfix,
Pull Requests hacia develop, qa y main.

\`\`\`
npm install
npm start
\`\`\`

## Endpoints
- POST   /tasks
- GET    /tasks
- GET    /tasks/:id
- PUT    /tasks/:id
- DELETE /tasks/:id
